# Sunboy Blinds hero

Buildless HTML, CSS and JavaScript. Serve `dist/` with a static HTTP server.

The logo is the user-supplied PNG, displayed with its surrounding white space cropped in CSS. The original image is unchanged.

The desktop/mobile videos and posters were copied from the retired John Crawford hero in `owner-copy-work/dist/assets`. That project was only read. Source edit: `20261017_120924.mp4` and `20261017_120958.mp4`, kitchen/living/dining montage. The November 4 replacement video was not used.

Only a hero and navigation are in scope. The navigation has Indoor / Outdoor, About and Service Area detail panels, plus a raised blue button opening the original video in a native dialog. There are no consultation or lead forms. The centered, two-line H1 and Tampa Bay service area are supplied by the user. A consultation URL or phone number has not been provided, so the button reads "See it in action" and opens the film. The accessibility route provides practical controls information. Public assistance contact details have not been supplied.

The two hero CTAs (Book a Consultation and Call Sunboy) are styled but disabled until the user supplies the consultation URL and phone number. The requested five-star Google and Facebook badges are design treatments; no profile URLs, verified ratings or review counts are supplied. The badges are not linked. This is an owner-private design preview.
